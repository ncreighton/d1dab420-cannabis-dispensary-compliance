== Description ==

A WordPress plugin for cannabis dispensaries and licensed retailers managing state compliance requirements. Features metrc-compatible inventory tracking with batch and lot number logging, daily seed-to-sale reporting with automated state manifest generation, customer age verification portal, product catalog with potency and terpene data, loyalty program management, and automated compliance alert reminders for license renewals and state reporting deadlines.

**Features:**

* Core functionality

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate via WordPress admin > Plugins
3. Configure via Settings > Cannabis Dispensary Compliance and Inventory Management WordPress Plugin
